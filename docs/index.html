Установка через USB

Прошивка дисплея
прямо из браузера

Выберите свою плату, подключите её к компьютеру и запустите установку. Python и PlatformIO не нужны.

Откройте эту страницу в Chrome или Edge на компьютере.

1 Выберите плату

2 Подключите и установите

Подключите плату к компьютеру USB-кабелем с передачей данных. Закройте программы, которые могут использовать её USB-порт.

Это полная установка. Сохранённые Wi-Fi и настройки Nightscout будут удалены. После установки настройте дисплей заново.

Сначала выберите плату по фотографии.

Этот браузер не поддерживает прошивку через USB. Используйте Chrome или Edge на компьютере.

Для установки откройте эту страницу по защищённой ссылке HTTPS.

В открывшемся окне выберите USB-порт платы, затем Install — «Установить». Не отключайте кабель до завершения.

Хотите сохранить настройки уже установленного дисплея? Обновите его из архива по инструкции релиза.

3 Настройте дисплей

После установки на экране появится QR-код. Подключите телефон к сети NS-Monitior-Setup, откройте 192.168.4.1 и укажите домашний Wi-Fi и адрес Nightscout.

Плата не появилась в списке портов

Попробуйте другой USB-кабель: некоторые кабели подходят только для зарядки. Подключите плату напрямую к компьютеру, закройте Serial Monitor и другие программы прошивки. Если порт не появился, откройте инструкцию своей платы: LilyGO T-Display S3 или M5Stack CoreS3.

Установка завершилась ошибкой

Не выбирайте другую модель платы. Проверьте кабель, переподключите устройство и повторите установку. Для установки из файла доступны архивы прошивок с инструкцией.
